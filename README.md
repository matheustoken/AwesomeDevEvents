# AwesomeDevEvents - REST APIs with ASP.NET Core Course

## Project Overview

AwesomeDevEvents is a programming events management project developed as part of the course *Creating REST APIs with ASP.NET Core*. The project is built using ASP.NET Core 7.

## Technologies and Tools Used

- Visual Studio 2022  
- ASP.NET Core 7  
- Entity Framework Core (EF Core)  
- Swagger (API documentation)  
- AutoMapper  

## Features

- Event management:  
  - Create events  
  - List events  
  - View event details  
  - Update events  
  - Delete events  

- Speaker management:  
  - Register speakers
